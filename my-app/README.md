# Инструкция по запуску

## Шаги для запуска проекта

1. **Перейдите в терминале в папку `my-app` и установите зависимости:**
   ```bash
   npm install
   ```

2. **После успешной установки запустите сервер разработки Webpack:**
   ```bash
   npm run dev
   ```


3. **Сервер разработки Webpack: запустится, и приложение откроется в браузере:**
   [ http://localhost:8000]
